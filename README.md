 Single-Cell Analysis of Macrophages within a heterocellular 3D PDAC spheroid

This repository contains the analysis pipeline for single-cell RNA-seq of pancreatic ductal adenocarcinoma (PDAC) spheroids with a focus on tumor-associated macrophages (TAMs). The pipeline enables data import, QC, clustering, supervised subclustering, marker-based PCA, and functional enrichment analyses, demonstrating how gold nanoparticle-assisted optoporation modulates TAMs within a 3D multicellular environment.

All custom functions extending Seurat functionality are provided via the SeuratExtend package.
